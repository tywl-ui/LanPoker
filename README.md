# LanPoker 局域网棋牌

> 可自定义规则的安卓棋牌工具：炸金花 + 斗地主（开发中），朋友局自动记账，局域网联机（规划中）。

斗地主类棋牌 App 通常锁死标准规则。这个项目反其道而行：**副数、人数、王的数量全部可调**，配合「自填倍数 + 自动记账」的账本系统，专为朋友线下聚会设计——不用联网、不用注册、不用掏手机算账。

## 特性

- **三种模式**
  - 好友局：一台手机轮流操作，聚会面对面玩
  - 人机快局：固定倍数（闷 1 底 / 看 2 底），选完自动亮牌，连开多把
  - 人机标准局：完整闷/看/跟/加/比/弃下注流程
- **AI 对手**：可配置任意 OpenAI 兼容大模型 API（DeepSeek / 通义千问 / 智谱 GLM / OpenAI 等），AI 用大模型思考；没配 API 或调用失败时自动用内置启发式 AI 兜底
- **自由配置**：1-3 副牌、2-8 人、0-6 张王（百搭）、底分可调，非法配置自动拦截
- **炸金花规则**
  - 开局每人自动下 **1 底注**；闷牌下注 = level 底；看牌下注 = **闷牌的 2 倍**
  - 后一家出的倍数**不能低于**上一家（跟注必须跟上，加注必须更高）；加注倍数可**自己填**
  - **比牌限制**：三家以上只能和**已看牌**的玩家比牌；仅剩两家时才能和闷牌的对手开牌
  - 比牌时**双方各付比牌费**（闷 1×/看 2× 当前 level），输者弃牌，平局发起者输
  - 牌型：豹子 > 顺金 > 金花 > 顺子 > 对子 > 单张，杂色 235 吃豹子（可关），A 可作低/高
  - 王 = 百搭牌：自动计算能组成最大牌型的补法；多副牌完全同牌型自动重发
- **记账系统**：本局明细、实时总分、会话账单一键导出（复制文本）
- **矢量美术**：程序绘制的牌面/牌背/筹码/头像，无版权问题，任意分辨率清晰

## 快速开始

环境要求：JDK 17、Android SDK（platform-35 + build-tools 35.0.0，路径写在 `local.properties` 的 `sdk.dir`）。

```bash
# 跑规则引擎单元测试（32 个用例）
gradlew.bat :core:test

# 编译调试 APK
gradlew.bat :app:assembleDebug
# 产物：app\build\outputs\apk\debug\app-debug.apk

# 安装到真机（需开启 USB 调试）
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

不会编译也行：直接用手机打开仓库 Releases 页面（或找作者要）的 APK 即可安装。

## 玩法说明（炸金花）

1. 开局配置：模式（好友局/人机快局/人机标准局）、副数、人数、王数量、底分；人机局可设 AI 人数，可在「AI 设置」里填自己的大模型 API
2. 每人发 3 张牌，围桌而坐，轮到谁谁操作（当前行动者固定在屏幕下方）
3. **闷牌**：不看牌直接下注，跟注 = level 底；**看牌**：翻看自己的牌，跟注 = **2×level 底**
4. 每轮可选：跟注（跟够时"过"）/ 加注（倍数必须高于当前 level，可自填）/ 比牌（付比牌费后与指定玩家比大小，输者弃牌，平局发起者输）/ 弃牌
5. 只剩一人时结束，赢家拿走底池（净收 = 底池 − 自己投入）
6. 系统自动记账：赢家 +净收，输家 -各自投入，实时总分，账单一键导出

牌型大小：`豹子 > 顺金 > 金花 > 顺子 > 对子 > 单张`，杂色 `235` 只压豹子，其余按单张算。

## AI 设置（人机模式）

「开始游戏」下方有「AI 设置」入口，填入任意 OpenAI 兼容服务的 Base URL + API Key + 模型名即可（如 DeepSeek、通义千问、智谱、OpenAI）。支持「测试连接」。不配置也能玩——AI 自动用内置启发式策略。

## 工程结构

```
├── core/                纯 Kotlin 规则引擎（零安卓依赖，全部单测覆盖）
│   ├── deck/            牌、牌堆、洗牌、发牌（多副 + 王）
│   ├── config/          公共配置模型 + 校验
│   ├── zjh/             炸金花牌型判定（王百搭 / 235 / 平局）
│   └── ledger/          记账：会话、流水、总分、账单导出
└── app/                 Android 应用（Kotlin + Jetpack Compose Material3）
    ├── ui/config/       配置页
    └── ui/zjh/          炸金花游戏页（传手机 → 亮牌 → 填倍数 → 记账）
```

详细规则与功能设计见 [docs/规则与功能设计.md](docs/规则与功能设计.md)（文档在仓库根部，后续会挪进 docs/）。

## 环境注意事项

Windows 下如遇 Gradle 测试 Worker 报 `ClassNotFoundException: GradleWorkerMain`，多为工程路径或用户目录含非 ASCII 字符导致（java.exe 解析长非 ASCII classpath 的已知问题）。解决：将工程放到纯英文路径，并把 `GRADLE_USER_HOME` 指到英文目录（`setx GRADLE_USER_HOME C:\gradle`）。
